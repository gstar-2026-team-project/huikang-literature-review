# TextWorld

TextWorld is a turn-based text-game framework stepped by `step(command)`.

| | |
|---|---|
| Year | 2018-20 |
| Demo | [Microsoft Research project page](https://www.microsoft.com/en-us/research/project/textworld/) (aka.ms/textworld): an animated GIF banner, a sample game transcript and the official "Getting Started with TextWorld" video (YouTube WVIIigrPUJs). Its [Try it](https://www.microsoft.com/en-us/research/project/textworld/try-it/) page embeds a human-playable sample game in a browser player, but the game file is gone and the player shows an error. ## Demo

- [project-page] [TextWorld project page](https://www.microsoft.com/en-us/research/project/textworld/): I rendered the page and read its text. It has an animated banner (`TextWorld-Animation-1970x720-v4.gif`, scrolling game text with a door and key) and a static sample transcript: "You are navigating through a house. You've just entered a serious study. ... Looks like there is a locked door. Find the key to unlock the door. You should try going east." It also embeds the YouTube video WVIIigrPUJs. It shows no agent or model playing.
- [official-video] [Getting Started with TextWorld](https://www.microsoft.com/en-us/research/video/getting-started-with-textworld/) (3:11, 18 March 2019, Côté and Tay): the caption reads "Watch this video to get started with using TextWorld!" The Videos tab also lists "First TextWorld Problems Challenge – Getting Started" (2:32, 25 March 2019). I could not watch the YouTube embed: in headless Chrome it showed "Video player configuration error" (Error 153), so I saw no frames. This is a tutorial recording, not a live run.
- [playable (broken)] [Try it](https://www.microsoft.com/en-us/research/project/textworld/try-it/): the page says "Try out an example game generated by TextWorld! Type out what you want to do next and see where the game takes you. (Hint: try "go east")". It embeds an iplayif.com (Parchment) player for `https://github.com/microsoft/TextWorld/releases/download/1.6.2/game1.z8`. When I loaded the player, it showed "Error: Could not fetch storyfile, got 500". The release asset returns HTTP 404, and the 1.6.2 release tag is not on GitHub. Typed commands ("look", "go east", ...) had no effect and sent no network requests. When it worked, it was a human-playable, turn-based game with no clock, which matches the Play mode label.
