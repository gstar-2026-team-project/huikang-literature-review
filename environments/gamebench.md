## Details

- In the turn-based or untimed contrast set: GameBench ([arXiv 2406.06613](https://arxiv.org/abs/2406.06613): board games such as Santorini where "two players take turns"). None of the contrast set has a native clock; a deadline could be imposed but the games do not reward reflexes. They are useful as the "same model, no clock" control.

## Demo

- [project page, not a demo] [GameBench project page](https://gamebench-website.vercel.app/): I rendered it in headless Chrome and dumped its text, media and network requests. It has author names, Paper/Code/arXiv buttons, the abstract, and one static image (overall_rating.webp), a box plot captioned "Aggregated strategic reasoning scores for each tested model–scaffolding configuration, computed from match results using the Bradley–Terry model and normalized". It has no video, iframe, canvas, replay viewer or playable game. Play-mode evidence: none observable. The repo ships its match data only as a raw [`matches.json`](https://github.com/Joshuaclymer/GameBench/tree/main/matches.json) file, with no viewer.
