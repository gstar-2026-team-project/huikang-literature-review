# LIBERO-LQ

LIBERO-LQ "decouples policy inference from environment stepping, enabling simulated execution to progress during non-negligible inference latency".

![Synchronous vs asynchronous action-chunk execution timelines](../assets/gifs/libero-lq.png)

*Figure from the project page comparing synchronous execution, where the robot waits during each 2-step inference, with asynchronous execution, where the next chunk is inferred while the previous chunk keeps running. Source: [LIBERO-LQ project page](https://vla2026.github.io/libero-lq).*
